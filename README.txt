MIET Campus Library Borrowing and Fine Management System  (COM-501 Python Assignment)

How to run (Python 3 required, no extra libraries):
    python main.py

Files
    main.py               - final console application (menu-driven)          [Milestone 5]
    library_utils.py      - user-defined module: fine, availability, summary [Milestone 4]
    library_account.py    - LibraryAccount class                             [Milestone 3]
    library_storage.py    - file handling: save/read records + input check   [Milestone 5]
    library_records.txt   - sample records created by the program
    main_milestone4.py    - Milestone 4 main program (module import + time demo)
    milestones/           - earlier versions: m1_basic_loan.py, m2_catalogue_loop.py, m3_oop.py
